# 上位机旧文件归档说明

本目录用于临时存放当前主流程不再直接使用的历史测试脚本、调参脚本和旧版草稿代码。

归档原则：

- 不直接删除旧代码，避免误删后无法恢复。
- 主目录只保留当前运行链路和近期仍在调试的入口。
- 如果后续发现某个脚本还需要使用，可以直接从本目录移回原位置。

- `zqwl_bot/comm.py`
- `zqwl_bot/qr1.py`
- `zqwl_bot/qr2.py`
- `zqwl_bot/block.py`
- `zqwl_bot/ring.py`
- `zqwl_bot/test_A&B.py`
- `zqwl_bot/test_C&D.py`
- `zqwl_bot/test_comm.py`
- `zqwl_bot/test_ring.py`
- `zqwl_bot/test_block_pass.py`
- `zqwl_bot/models/`
